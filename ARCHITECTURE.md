# ARCHITECTURE.md

## Компоненты

```
adaptive_ai/
  app/          CLI и конфигурация
  core/         контракты, оркестратор, политики
  models/       бэкенды языковых моделей (ModelBackend)
  memory/       долговременная память (MemoryStore, SQLite)
  tools/        реестр и встроенные инструменты, MCP-мост
  evaluation/   оценка качества, тестовые наборы
  learning/     накопление опыта, Trainer (заглушка)
  skills/       библиотека навыков (заглушка)
  tests/        автоматические тесты
  scripts/      вспомогательные скрипты
```

## Контракты

- `ModelBackend` — генерация, возможности модели, загрузка/сохранение состояния.
- `MemoryStore` — сохранение/поиск/обновление/удаление воспоминаний и фактов.
- `ToolRegistry` — регистрация и вызов инструментов.
- `Trainer` — обучение (отдельный процесс, не блокирует основной цикл).

## Зависимости

- `numpy` (обязательная)
- `pytest` (тесты)
- `rwkv` (опционально, PyTorch бэкенд)
- `mcp` (опционально, этап 8)

## Пути

Все пути настраиваются через переменные окружения / `Config`:
- `ADAPTIVE_AI_DATA_DIR`
- `ADAPTIVE_AI_MODELS_DIR`
- `ADAPTIVE_AI_DB_PATH`
- `ADAPTIVE_AI_MODEL_BACKEND`
- `ADAPTIVE_AI_MODEL_PATH`

Большие модели и пользовательские данные не входят в репозиторий/образ.
