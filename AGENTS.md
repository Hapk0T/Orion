# AGENTS.md

Инструкции для OpenCode и разработчиков проекта Adaptive Intelligence.

## Цель

Создать модульную локальную ИИ-систему, способную сохранять точные знания, использовать инструменты, учиться на проверенном опыте и в перспективе развивать собственную нейросеть.

## Текущий этап

Этап 2 — Минимальный рабочий CLI. Этап 0 и 1 завершены.

## Режим без модели (fallback)

Если файл модели не найден в `./models`, CLI работает в режиме fallback:
- `chat` — эхо-ответ с пометкой [режим без модели]
- `solve` — базовый ответ без использования инструментов
- Когда пользователь положит модель в `./models` и укажет `ADAPTIVE_AI_MODEL_PATH`, система автоматически переключится на реальную генерацию через rwkv.cpp

## Как работать

1. Не переписывайте исправные модули без необходимости.
2. Каждая подсистема — через интерфейс (`Protocol`). Оркестратор не зависит от SQLite/конкретной LLM/MCP.
3. Не добавляйте тяжёлые зависимости без проверки совместимости с i7-3612QM (без AVX2, CPU only).
4. Большие модели и пользовательские данные — не в Git (`data/`, `models/`).
5. После каждого этапа: тесты, документация, работающий код.

## Команды

- `python -m adaptive_ai.app.main chat "текст"` — диалог
- `python -m adaptive_ai.app.main solve "задача"` — задача с инструментами
- `pytest` — автоматическое тестирование
- `docker compose up --build` — запуск в контейнере

## Ограничения целевого железа

- i7-3612QM: нет AVX2 → rwkv.cpp собирать с `RWKV_AVX2=OFF RWKV_AVX=OFF RWKV_FMA=OFF`
- 16 ГБ RAM → маленькие квантованные модели (169M–1.5B)
- GT 620M: не рассчитывать на ускорение LLM
