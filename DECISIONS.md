# DECISIONS.md

## Архитектурные решения

### Mодель: RWKV через rwkv.cpp (CPU)
- Причина: RWKV CPU-friendly, состояние фиксированного размера, подходит для слабого CPU.
- Риск: i7-3612QM нет AVX2 → собираем с `RWKV_AVX2=OFF RWKV_AVX=OFF RWKV_FMA=OFF`.
- Альтернатива: чистый Python + PyTorch (`rwkv` пакет) — работает на любом CPU, медленнее.

### Память: SQLite + FTS5
- Причина: простая, надёжная, транзакции, миграции, нет лишних зависимостей.
- Векторный поиск — опционально, после измерения базового качества.

### Инструменты: встроенные + MCP через отдельный адаптер
- Оркестратор не привязан к MCP.

### Обучение: отдельный процесс, не блокирует основной цикл
- Четыре уровня адаптации явно различаются (память ≠ веса).

### Docker
- Образ без моделей и пользовательских данных (volumes).
- Сборка без AVX2 для совместимости со старыми и новыми CPU.
